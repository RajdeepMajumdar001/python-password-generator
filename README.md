# PASSWORD-GENERATOR
A simple and secure command-line password generator built using Python's standard library.

Generate random passwords with two complexity levels: Simple and Complex.

# Technologies Used
- Python 3
- Secrets
- string

## Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/RajdeepMajumdar001/python-password-generator.git
```

**Step 2: Navigate to the project directory**

```bash
cd python-password-generator
```
## Usage

**Run the program:**

```bash
python main.py
```

**Select your preferred password complexity:**

```text
Choose Password complexity
1. Simple
2. Complex

Enter your choice (1/2):
```
